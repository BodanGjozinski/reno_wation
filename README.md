# RenovateBySeeing

A personal web app for viewing a captured room in 3D and trying changes on it.
This first piece is the scene viewer: it opens the Gaussian splat files that
Postshot or Brush export and lets you work on them in the browser.

## What it does

- **Add scenes** by dropping a `.ply`, `.spz`, `.splat` or `.ksplat` file on the page.
  Scenes are kept in this browser (IndexedDB), so nothing is uploaded anywhere.
- **Upright** flips Postshot/Brush exports (COLMAP axes, Y down) so the floor is down.
- **Set scale**: click two points you know the distance between (a door width),
  type the real distance in metres, and the room is scaled to real size.
- **Paint zone**: a box that recolours everything inside it. Move, size and turn it
  with the handles, and pick the colour in the side panel.
- **Hide zone**: a box that hides everything inside it, for removing old furniture.
- Settings and zones are saved per scene and come back when you reopen it.
- **Try the sample room** loads a small synthetic room so you can test without a capture.

## Run it

Needs Node 20 or newer.

```bash
npm install
npm run dev      # opens on http://localhost:5173
npm run build    # static site in dist/, host it anywhere
```

The sample room is generated by `scripts/make-sample-room.mjs` before `dev` and `build`.

## Getting a scene from Postshot

Export with **SPZ, version 4, quality 4 to 5, spherical harmonics 1** for small files,
or PLY for full quality. On Postshot's free plan, export the cameras and points
instead and train the final scene in Brush, which exports PLY.
The full capture and export walkthrough is in the Postshot guide doc.

## How it is built

- [three.js](https://threejs.org) 0.180 for the scene, camera and handles.
- [Spark](https://sparkjs.dev) 2.3 renders the splats and does the recolour and
  hide zones (`SplatEdit` with box SDFs).
- [Vite](https://vite.dev) for the dev server and build. No framework.

| File | Job |
| --- | --- |
| `src/viewer.js` | three.js scene, splat loading, framing, zones, measuring |
| `src/library.js` | Saving scenes and their settings in IndexedDB |
| `src/main.js` | Wires the page's buttons, panels and drag-and-drop to the viewer |
| `src/style.css` | Layout and theme (follows light/dark mode) |

## Known limits

- Paint zones set a flat colour, so light and shadow inside the zone are lost.
- Zones are boxes; walls at odd angles need the Turn handle.
- Big PLY files (hundreds of MB) load slowly; prefer SPZ.
